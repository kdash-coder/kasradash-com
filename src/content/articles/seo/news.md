**SEO news on this site means one dated post per Google update, written from tracked data, not from the announcement.** [Kasra Dash](https://kasradash.com/) tracks 13,000 sites with no defined entity and 3,500 exact match domains, so each post says what got hit, which patterns explain it, and what to change. Each one is updated as the rollout completes.

## How each update post is written

**Every post follows the same shape so you can compare updates side by side.**

1. What Google announced, with the date and the primary source.
2. What the tracked data shows: which kinds of site were hit, with the percentages.
3. The patterns behind it, one section each.
4. What is winning instead.
5. An audit you can run on your own site the same day.
6. The video breakdown.

## Why update posts sit apart from the guides

**A Google update is a dated event; a guide is evergreen.** Keeping them apart means the [technical SEO guide](/seo/technical-seo/) stays a guide, and the update posts stay a record. When you are diagnosing a drop, start with the post for the update closest to the date it happened, then use the [entity optimisation guide](/seo/content-seo/entity-optimisation/) and the [E-E-A-T framework](/seo/seo-frameworks/eeat-framework/) for the fix.
