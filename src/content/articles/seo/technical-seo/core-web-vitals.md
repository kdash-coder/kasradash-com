## What Are Core Web Vitals?

**Core Web Vitals are a set of performance metrics that measure how users experience a webpage in terms of loading speed, interactivity, and visual stability.**

Google evaluates three primary metrics:

| Metric | Measures | Good Score | Needs Improvement | Poor |
| --- | --- | --- | --- | --- |
| **Largest Contentful Paint (LCP)** | Loading speed | ≤ 2.5s | 2.6–4.0s | > 4.0s |
| **First Input Delay (FID)** | Interactivity (soon replaced by INP) | ≤ 100ms | 100–300ms | > 300ms |
| **Cumulative Layout Shift (CLS)** | Visual stability | ≤ 0.1 | 0.1–0.25 | > 0.25 |

### Supporting Metrics

- **Interaction to Next Paint (INP):** Measures response latency more accurately than FID.
- **First Contentful Paint (FCP):** Tracks when the first visible content appears on-screen.

→ Deepen your understanding of performance metrics in **Website Speed SEO** and ensure clean accessibility via [**Fix Indexing Issues**](/seo/technical-seo/).

Core Web Vitals define whether your website feels instant or frustrating.

## Why Core Web Vitals Matter

In 2021, Google’s **Page Experience Update** officially made Core Web Vitals a ranking factor, rewarding fast, stable, and responsive websites.

Today, these metrics directly influence how search algorithms interpret **user experience (UX)**.

**Fast websites → reduce → bounce rates.**  
**Stable layouts → improve → engagement and conversions.**  
**Responsive pages → enhance → mobile rankings.**

As a result, improving Core Web Vitals supports:

- Higher organic rankings.
- Stronger engagement and dwell time.
- Better conversion rates and trust signals.

→ See how algorithmic changes affect UX metrics in [**Google Algorithm Updates**](/seo/technical-seo/google-algorithm-updates/) and learn how to verify site performance in [**Technical SEO Audit**](/seo/technical-seo/).

Google now ranks based on experience, not just information.

### Are Core Web Vitals the same as PageSpeed?

No. **PageSpeed** measures overall performance, while **Core Web Vitals** focus specifically on real-world user experience signals that impact SEO.

## How to Measure Core Web Vitals

You can measure your Core Web Vitals using both **field data** (real user experience) and **lab data** (simulated tests).

### Which metric should I fix first?

Start with **LCP** (Largest Contentful Paint), as slow loading directly impacts both rankings and user retention.

## How to Improve Core Web Vitals

Once you’ve identified poor-performing metrics, you can optimise them systematically.

### 1. Optimise Largest Contentful Paint (LCP)

**Goal:** Ensure your main content loads within 2.5 seconds.  
**Fixes:**

- Compress and resize images.
- Use **lazy loading** for off-screen assets.
- Minify CSS and JavaScript.
- Implement **CDN caching**.
- Preload critical assets.

→ For advanced load-time strategies, see **Website Speed SEO**.

### 2. Reduce First Input Delay (FID) / Improve Interaction to Next Paint (INP)

**Goal:** Make pages respond to user input within 100ms.  
**Fixes:**

- Minimise long JavaScript tasks.
- Defer non-critical scripts.
- Use **Web Workers** for heavy computation.
- Split bundles for faster interactivity.

→ Understand rendering in [**JavaScript SEO**](/seo/technical-seo/javascript-seo/).

### 3. Minimise Cumulative Layout Shift (CLS)

**Goal:** Prevent elements from shifting unexpectedly.  
**Fixes:**

- Always define width and height for images and videos.
- Reserve space for ads and embeds.
- Avoid inserting DOM elements above existing content.
- Implement font-display: swap for custom fonts.

→ Learn how stable rendering supports rankings in [**Mobile-First Indexing**](/seo/technical-seo/mobile-first-indexing/).

Fixing Core Web Vitals is less about tools and more about restraint, load less, render faster, stabilise early.

## How Core Web Vitals Affect Crawling & Indexing

Poor performance doesn’t just frustrate users, it affects Google’s ability to **crawl and index** your content.

Slow, unstable pages consume more **rendering budget**, meaning Googlebot may skip or delay crawling your resources.

**Optimised Core Web Vitals → improve → crawl efficiency and index freshness.**

### Technical Impacts

- **Crawl Budget:** Fast, stable pages allow Googlebot to visit more URLs.
- **Render Budget:** Efficiently structured pages reduce processing time.
- **Mobile-First Indexing:** Mobile performance directly influences rankings.

→ See how performance connects to discoverability in [**Google Crawling & Indexing**](/seo/technical-seo/google-crawling-and-indexing/) and **Mobile-First Indexing**.

Performance is not cosmetic, it determines whether your content even gets seen.

### Do Core Web Vitals affect all pages equally?

Yes, every page Google indexes is evaluated independently, meaning one poor-performing URL can drag down your site’s overall quality signals.
